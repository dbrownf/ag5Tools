# Preparing APSIM meteorological files with ag5Tools

<div class="section level2">

## Overview

The [APSIM](https://www.apsim.info/) crop modelling platform requires a
site meteorological file containing daily weather observations with
specific variable names, units, and header metadata. `ag5_apsim()`
automates this workflow:

1.  Extracts the required AgERA5 variables from locally downloaded `.nc`
    files.
2.  Applies unit conversions (Kelvin → °C, J/m²/day → MJ/m²/day).
3.  Computes the site constants `tav` and `amp`.
4.  Writes a ready-to-use `.met` file (classic APSIM) or `.csv` +
    constants file (APSIM Next Generation).

</div>

<div class="section level2">

## Variable mapping

| APSIM column | AgERA5 variable      | Statistic | Unit conversion                  |
|--------------|----------------------|-----------|----------------------------------|
| `maxt`       | Temperature-Air-2m   | Max-24h   | K → °C                           |
| `mint`       | Temperature-Air-2m   | Min-24h   | K → °C                           |
| `rain`       | Precipitation-Flux   | —         | none (mm/day)                    |
| `radn`       | Solar-Radiation-Flux | —         | J/m²/day ÷ 1 000 000 → MJ/m²/day |
| `wind`       | Wind-Speed-10m       | Mean      | none (m/s)                       |
| `vp`         | Vapour-Pressure      | Mean      | none (hPa)                       |
| `rh`         | Relative-Humidity-2m | —         | none (%)                         |

`maxt`, `mint`, `rain`, and `radn` are the four variables required by
APSIM for all simulations. `wind`, `vp`, and `rh` are optional but used
by several crop modules.

</div>

<div class="section level2">

## Site constants: `tav` and `amp`

APSIM `.met` files carry two header constants derived from the weather
record:

-   **`tav`** — annual average temperature (°C), computed as the mean of
    `(maxt + mint) / 2` across all days.
-   **`amp`** — half the range between the warmest and coolest monthly
    mean temperatures (°C), computed as
    `(max(monthly_mean_temp) - min(monthly_mean_temp)) / 2`.

`ag5_apsim()` computes both constants automatically from the extracted
data.

</div>

<div class="section level2">

## Controlling which variables are extracted

The `variables` argument accepts three forms:

| Value             | Variables extracted                                          |
|-------------------|--------------------------------------------------------------|
| `"all"` (default) | maxt, mint, rain, radn, wind, vp, rh                         |
| `"required"`      | maxt, mint, rain, radn                                       |
| character vector  | any subset, e.g. `c("maxt", "mint", "rain", "radn", "wind")` |

</div>

## Examples

<div class="section level3">

### Return a data.frame (no file written)

When `filename = NULL` (the default), `ag5_apsim()` returns an annotated
`data.frame` and prints the site constants to the console.

<div id="cb1" class="sourceCode">

``` r
library(ag5Tools)

met <- ag5_apsim(
  coords     = c(36.68, -3.37),   # lon, lat — Arusha, Tanzania
  start_date = "2015-01-01",
  end_date   = "2015-12-31",
  variables  = "required",
  path       = "C:/agera5_data"
)

head(met)
#>   year day   maxt   mint  rain      radn
#> 1 2015   1  27.43  17.89  0.00  19.42
#> 2 2015   2  28.12  18.03  0.00  20.11
#> 3 2015   3  26.78  17.61  2.34  15.73
#> ...

attr(met, "tav")
attr(met, "amp")
```

</div>

</div>

<div class="section level3">

### Write a classic APSIM .met file

Set `filename` to a path without extension; `ag5_apsim()` appends
`.met`.

<div id="cb2" class="sourceCode">

``` r
ag5_apsim(
  coords     = c(36.68, -3.37),
  start_date = "2015-01-01",
  end_date   = "2015-12-31",
  path       = "C:/agera5_data",
  filename   = "C:/apsim/arusha_2015",
  format     = "classic"
)
```

</div>

The output file `arusha_2015.met` looks like:

    longitude = 36.68 (degrees)
    tav = 20.34 (oC)

    () () (MJ/m2) (oC) (oC) (mm) (m/s) (hPa) (%)
    2015 1 19.42 27.43 17.89 0.00 2.3 18.4 71
    2015 2 20.11 28.12 18.03 0.00 1.9 17.9 68
    ...

### Write an APSIM Next Generation file

For APSIM Next Generation, use `format = "apsimng"`. This writes two
files: `arusha_2015.csv` (data) and `arusha_2015_constants.txt` (site
metadata).

<div id="cb4" class="sourceCode">

``` r
ag5_apsim(
  coords     = c(36.68, -3.37),
  start_date = "2015-01-01",
  end_date   = "2015-12-31",
  path       = "C:/agera5_data",
  filename   = "C:/apsim/arusha_2015",
  format     = "apsimng"
)
```

</div>

<div class="section level3">

### Download missing files automatically

If AgERA5 files for the requested period are not yet on disk, set
`download = TRUE`. The function will fetch any missing files before
extracting, using the location derived from `coords` as the bounding
box.

<div id="cb7" class="sourceCode">

``` r
ag5_apsim(
  coords     = c(36.68, -3.37),
  start_date = "2015-01-01",
  end_date   = "2015-12-31",
  path       = "C:/agera5_data",
  filename   = "C:/apsim/arusha_2015",
  download   = TRUE
)
```

</div>

</div>

<div class="section level3">

### Relative humidity time-of-day

`rh` is extracted at a specific time of day. The default is `"09h"`. Use
`rh_time` to change this.

<div id="cb8" class="sourceCode">

``` r
ag5_apsim(
  coords     = c(36.68, -3.37),
  start_date = "2015-01-01",
  end_date   = "2015-12-31",
  variables  = c("maxt", "mint", "rain", "radn", "rh"),
  rh_time    = "12h",
  path       = "C:/agera5_data",
  filename   = "C:/apsim/arusha_2015_rh12"
)
```

</div>

<div class="section level2">

## Multi-year records

To build a multi-year `.met` file, extend the date range. `ag5_apsim()`
handles leap years correctly via R’s `seq.Date()`.

<div id="cb9" class="sourceCode">

``` r
ag5_apsim(
  coords     = c(36.68, -3.37),
  start_date = "2010-01-01",
  end_date   = "2020-12-31",
  path       = "C:/agera5_data",
  filename   = "C:/apsim/arusha_2010_2020",
  format     = "classic"
)
```

</div>
