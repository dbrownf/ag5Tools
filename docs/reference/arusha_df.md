# Example dataset for the ag5Tools package

<div class="ref-description section level2">

100 random points in the Arusha region, Tanzania, with date ranges for
demonstration of `ag5_extract`. The geographic coordinates were
generated with the function `st_sample` from the sf package.

</div>

<div class="section level2">

## Usage

<div class="sourceCode">

``` r
arusha_df
```

</div>

</div>

<div class="section level2">

## Format

A `data.frame` with 100 rows and 4 columns:

-   lon:

    numeric. Longitude in decimal degrees (WGS84).

-   lat:

    numeric. Latitude in decimal degrees (WGS84).

-   start_date:

    character. Start date in `"YYYY-MM-DD"` format.

-   end_date:

    character. End date in `"YYYY-MM-DD"` format.

</div>
